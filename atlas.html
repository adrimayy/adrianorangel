Where should you live?

An interactive map that scores every country and 744 cities on 23 factors (jobs, money left after rent, healthcare, safety, freedom, climate, clean air and more). A 7-question quiz re-weights everything for you: your languages, your passports, your home city. Available in 8 languages.

Open it · Code

Why

It started as my own search for where to live. I wanted a ranking where every number has a published source I can check, and that anyone can re-weight for themselves.

How it works

  • Data pipeline (Python). Every figure comes from a published source (WHO, UN, FBI, BLS, Census, Eurostat, Freedom House, the World Happiness Report and others), stored one file per topic with its source and year. A build script turns them into 1–5 scores, with every cut-off in one file.
  • Missing data. About a quarter of country values aren't published, and the gaps cluster in poorer, smaller countries. They're filled by a model using wealth, size and region, drawn 20 times so the uncertainty carries through, and tested by hiding known values. A factor whose estimates are off by more than a point isn't filled at all.
  • Uncertainty. Each score is recalculated 120 times with values moved by their likely error, so the page shows a range, not just a number. A sensitivity analysis (Sobol indices) checks how much the ranking depends on my own judgment calls.
  • Front end. Plain JavaScript, HTML and CSS with no build step, split into one file per part (quiz, scoring, map, panels).
  • Tests. Playwright clicks through the quiz, map and language switch on desktop and mobile. Other checks cover specific numbers, translations and data age, and a monthly GitHub Action flags sources older than a year.

How it changed

53 versions so far. The early ones show why the sourcing rules matter. The first formula put New York on top. Once New York's strongest factors turned out to be estimates and were replaced with published data, Utrecht led. Later versions added a measured job market and real temperatures, expert-style review (two measures that both counted rent were merged into one), any visitor's languages and passports, and every US metro area. The full history is in the changelog, and the method is on one page.
